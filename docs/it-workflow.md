# IT 工作流说明

## 流程原则

**需求 → 分析梳理 → 来回确认 → 明确指令 → 执行**

严禁跳步，严禁擅自修改数据、代码、配置。

## 迭代环节

### 1. 需求阶段
- 需求收集与整理
- 需求分析 & 评审
- 输出：需求文档、评审纪要

### 2. 设计阶段
- 架构设计 / 技术选型
- 编码方案、接口设计
- 输出：设计文档、ER 图、序列图

### 3. 任务开发
- 任务拆解、分支开发
- 代码评审 CR
- 输出：代码、单元测试

### 4. Bug 修复 & 集成
- 缺陷跟踪、修复验证
- 版本合并、发布包
- 输出：修复单、发布说明

### 5. 测试验证
- 功能测试、回归测试
- 性能/兼容性测试
- 输出：测试报告

### 6. 开发质量保证
- 代码质量关口：CI Lint、单元覆盖率
- 文档同步
